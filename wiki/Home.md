# Purus.Drive Wiki

Welcome to the Purus.Drive documentation! This wiki provides comprehensive information about the app's features, architecture, and usage.

## What is Purus.Drive?

Purus.Drive is a comprehensive iOS application designed for professional drivers, fleet operators, and vehicle owners to:

- **Track Multiple Vehicles** - Manage cars, vans, trucks, trailers, boats, motorcycles, and more
- **Perform Pre-Trip Inspections** - Use customizable checklists to ensure vehicle safety before driving
- **Log Drives** - Document trips with mileage, dates, and notes
- **Sync Across Devices** - Keep data synchronized across multiple iOS devices using iCloud
- **Ensure Compliance** - Maintain proper records for commercial driving requirements

## Key Features

- 📱 **Native iOS App** - Built with SwiftUI for iOS 17+
- 🚗 **Multi-Vehicle Support** - Track unlimited vehicles and trailers with photos
- ✅ **Pre-Trip Checklists** - Reusable inspection templates for different vehicle types
- 📝 **Drive Logging** - Record trips with start/end mileage and notes
- ☁️ **iCloud Sync** - Automatic synchronization with conflict resolution
- 🔄 **Import/Export** - Backup and restore data in JSON format
- 📷 **Plate Scanner** - Built-in license plate recognition using Vision framework
- 🔒 **Privacy First** - All data stored locally or in your private iCloud container

## Quick Start

1. **Install** the app on your iOS device
2. **Choose Storage Mode** - Local storage or iCloud sync (Settings)
3. **Add Your First Vehicle** - Tap + to create a vehicle profile
4. **Create a Checklist** - Set up a pre-trip inspection template
5. **Log a Drive** - Record your trips with mileage tracking
