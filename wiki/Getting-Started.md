# Getting Started

Welcome to Purus.Drive! This guide will help you get up and running quickly.

## Installation

### Requirements

- iOS device running iOS 17.0 or later
- iPadOS device running iPadOS 17.0 or later
- iCloud account (optional, for sync)
- Approximately 50 MB of free storage

### Installing the App

1. Download Purus.Drive from the App Store
2. Tap **Install**
3. Launch the app
4. Grant necessary permissions (Camera, Photos)

## First Launch

### Initial Setup

When you first launch Purus.Drive:

1. **Welcome Screen** - Brief introduction to the app
2. **Storage Mode** - Choose between Local or iCloud storage
3. **Tutorial** (optional) - Quick walkthrough of features

### Choosing Storage Mode

**Local Storage** (Recommended for single device):
- ✅ Data stored only on this device
- ✅ Fast and works offline
- ✅ No iCloud account needed
- ❌ No sync across devices

**iCloud Storage** (Recommended for multiple devices):
- ✅ Data syncs across all your devices
- ✅ Automatic backup to iCloud
- ✅ Conflict resolution built-in
- ❌ Requires iCloud account
- ❌ Uses iCloud storage quota

**Decision Guide:**
- Choose **Local** if you only use one device
- Choose **iCloud** if you use multiple iOS devices
- You can change this later in Settings

## Quick Start Tutorial

### Step 1: Add Your First Vehicle

1. Tap the **+** button in the top-right corner
2. Select your vehicle type (Car, Truck, Van, etc.)
3. Fill in the details:
   ```
   Brand/Model: Toyota Camry
   Color: Silver
   Plate: ABC123
   ```
4. Optionally add a photo
5. Tap **Save**

Your first vehicle is now in the system!

### Step 2: Create a Checklist Template

Pre-trip inspections are important for safety and compliance.

1. Navigate to the **Checklists** tab
2. Tap the **+** button
3. Name your checklist:
   ```
   Title: Car Pre-Trip Inspection
   Vehicle Type: Car
   ```
4. Add checklist items:

   **Tires Section:**
   - Check tire pressure
   - Check tire tread depth
   - Inspect for damage

   **Lights Section:**
   - Test headlights
   - Test brake lights
   - Test turn signals

   **Fluids Section:**
   - Check oil level
   - Check coolant level
   - Check washer fluid

5. Tap **Save**

Your checklist template is ready to use!

### Step 3: Log Your First Drive

1. Navigate to the **Drive Logs** tab
2. Tap the **+** button
3. Fill in the details:
   ```
   Date: Today
   Vehicle: Toyota Camry
   Start km: 45000
   End km: 45150
   Reason: Commute to work
   ```
4. Attach your pre-trip checklist
5. Go through each checklist item:
   - Tap each item to mark it as ✓ (OK)
   - Add notes if needed
6. Tap **Save**

You've logged your first drive with a complete inspection!

## Common Tasks

### Adding a Trailer

1. Tap **+** button
2. Select **Trailer** type
3. Enter details:
   ```
   Brand/Model: 16ft Cargo Trailer
   Color: White
   Plate: TRL456
   ```
4. Add photo (optional)
5. Save

### Linking a Trailer to a Vehicle

1. Edit the vehicle
2. Scroll to **Trailer** section
3. Tap **Select Trailer**
4. Choose the trailer from the list
5. Save

The trailer is now linked to the vehicle!

### Performing a Pre-Trip Inspection

1. Create a new drive log
2. Select the vehicle
3. Attach a pre-trip checklist
4. Go through each item:
   - ✓ **Selected** - Everything is OK
   - N/A **Not Applicable** - Doesn't apply
   - ✗ **Not OK** - Issue found
5. Add notes for any issues
6. Complete the drive log

### Reviewing Drive History

1. Navigate to **Drive Logs** tab
2. Scroll through the list
3. Tap on any log to view details
4. See:
   - Vehicle used
   - Distance traveled
   - Checklist results (if attached)
   - All notes and details

## Working with Photos

### Adding Vehicle Photos

1. Edit a vehicle
2. Tap the photo placeholder
3. Choose:
   - **Take Photo** - Use camera
   - **Choose from Library** - Select existing photo
4. Crop/adjust if needed
5. Photo is saved automatically

**Tips:**
- Use good lighting for best results
- Include the whole vehicle in frame
- Use landscape orientation

### Using the Plate Scanner

1. When entering a license plate
2. Tap the camera icon
3. Point camera at the plate
4. Wait for automatic detection
5. Tap the detected text to use it

**Benefits:**
- Faster than typing
- Reduces errors
- Works with most plate formats

## Working with Multiple Devices

If you enabled iCloud sync, your data automatically syncs across devices.

### Setting Up Additional Devices

1. Install Purus.Drive on second device
2. Sign into the same iCloud account
3. Launch the app
4. Enable iCloud Sync in Settings
5. Wait for sync to complete

All your data appears on the second device!

### Understanding Sync

**When Sync Happens:**
- When you launch the app
- When you resume the app from background
- When you manually trigger sync

**What Gets Synced:**
- All vehicles and trailers
- All drive logs
- All checklists
- All photos
- Relationships between items

**Sync Conflicts:**
- If the same item is edited on two devices, you'll be asked to choose which version to keep
- See the [Features Guide](Features.md#icloud-sync) for details

## Backing Up Your Data

Even with iCloud sync, it's good practice to export backups.

### Creating a Backup

1. Open **Settings**
2. Tap **Export Data**
3. Choose **All Data**
4. Select **JSON** format
5. Tap **Export**
6. Save to Files or share via email

**Recommended:**
- Export monthly
- Export before major changes
- Keep backups in multiple locations

### Restoring from Backup

1. Open **Settings**
2. Tap **Import Data**
3. Select your backup JSON file
4. Review the preview
5. Choose **Merge** or **Replace**
6. Tap **Import**
